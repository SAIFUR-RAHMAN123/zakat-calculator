## 📌 About The Project

**Zakat Calculator** is a web-based calculator that provides an easy way to estimate Zakat based on the value of eligible assets.

The project is designed with a clean and simple interface so users can enter their financial values and quickly get an estimated Zakat amount.

The calculator uses the commonly applied **2.5% Zakat rate** for eligible wealth.

> **Note:** This calculator is intended for estimation and educational purposes. Zakat obligations can depend on individual circumstances and applicable scholarly guidance.
